## 🎯 Technical Architecture

### Auto-Detection System
```
User launches: python3 core/auto_detect.py
  ↓
Detects: OS (Mac/Windows/Linux) + Architecture (ARM/x86_64)
  ↓
Selects appropriate launcher:
  • Mac M1/M2/M3 → launch_tart.sh (Tart/Apple Virtualization)
  • Mac Intel → launch_utm.sh (UTM/QEMU)
  • Windows → launch_docker.bat (Docker Desktop)
  • Linux → launch_docker.sh (Docker Engine + KVM)
  ↓
Downloads/launches macOS VM with full DevOps stack
  ↓
Student has complete environment in 2-10 minutes
```

### DevOps Stack Included
- **Docker** + **Kubernetes** (k3s)
- **Jenkins** CI/CD
- **GitLab** source control
- **Grafana** + **Prometheus** monitoring
- **Terraform** Infrastructure as Code
- **Ansible** configuration management
- All running in containerized macOS environment
